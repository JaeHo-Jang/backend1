node모듈은 기본적으로 깃허브에 올라가지 않음

따라서

src 가보면 .gitignore에 가보면
/node_modules가 있는데 그걸 지우면 폴더가 지워짐.


======================== 
집이나 이동시 깃허브에서 풀로 땡겨왔는데
node_modules가 없을 경우

"npx i" 를 치면
node_modules이 깔림.


**버전으로 인해 오류나는 경우
npx create-react-app @@@이후
cd @@@ 이동후
npm start를 햇을때 버전 오류가 나는 경우에
npm i vitals
npm i web-vitals 입력 후 다시 스타트하면 됨
